# Elizabeth Aven Photography

Static portfolio site for Elizabeth Aven Photography.

## Repository structure

- `index.html` — site markup, styles, and scripts
- `assets/images/branding/` — logo and brand/owner imagery
- `assets/images/portfolio/` — portfolio photos organized by session type
- `assets/images/packages/` — legacy/package imagery retained for future use
- `CNAME` — GitHub Pages custom domain

The homepage uses a rotating three-photo portfolio preview. The full collection opens in an in-page modal and can be filtered by Couples, Families, Seniors, and Headshots.
